Política de Privacidade — JobHunter CV

Última atualização: 09/10/2026

O JobHunter CV é uma ferramenta pessoal de uso único (single-user).

Dados acessados

Acessa arquivos do Google Drive e Google Docs do próprio usuário, exclusivamente para: (a) criar uma cópia de um documento-modelo de currículo; (b) substituir a data do rodapé; (c) exportar a cópia em PDF.

Uso dos dados

Usados somente para gerar o PDF do currículo do usuário. Nenhum dado de usuário do Google é analisado, vendido ou compartilhado.

Armazenamento

Os PDFs gerados ficam armazenados localmente no computador do próprio usuário. Cópias temporárias no Google Drive são excluídas imediatamente após a geração do PDF.

Compartilhamento

Nenhum. O app não transmite dados do usuário a nenhum serviço externo.
